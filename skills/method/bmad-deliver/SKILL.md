name: bmad-deliver
description: 'Run an idea, research dump, brainstorm, or Forge output through bounded, resumable BMad delivery for code, documents, or both. Use when the user delegates idea-to-deliverable work or asks to resume an existing delivery run.'
---

Use [the command and run contract](references/run-record.md). For new work, save the user's message and authorized source excerpts in a raw intake envelope. Use `--intake` to route that material inside Delivery. A caller with a complete structured request can use `--request`. To continue work, use the [pinned runtime](references/run-record.md#pin-the-runtime-for-saved-runs) to inspect the saved run with `status` and follow its gate.

Capture the owner's intended outcome, constraints, original acceptance behaviors, output class when stated, and authority. Mode A asks the owner to approve a proposal. Mode B delegates within the owner's prose limits and exact [structured boundaries](references/run-record.md#mode-b-delegation). Mode C names the deliverable. Preserve the original checks and ask the owner for missing decisions. Record owner-supplied fields without inferring authorization from a classification or source excerpt.

Confirm that the user has authorized the material and the selected subscription session. Before starting model work, verify included allowance and that paid continuation is disabled. Codex is the supported subscription intake path. Claude Code workspace intake is a preview with deterministic checks only. Use the matching [subscription launch](references/run-record.md#subscription-backed-intake) and [workspace host steps](references/native-host.md). A pause can be resolved by the owner within the same run. Use a manual route with trusted local workers if the user chooses that path.

Check [current capabilities](references/run-record.md#beta-capabilities). Native code uses Build Auto. Native documents use Product Brief. Mixed runs use both in that order. Use a POSIX host with Python 3.11 or later. Native workflows need `uv` and a workspace agent that can run workflow tools and launch reviewers. Retain the requested [language settings](references/run-record.md#native-language-settings), with English as the default. Keep deliverables run-local and within the 4 MiB limit for each serialized JSON receipt.

Use [typed acceptance checks](references/run-record.md#acceptance-checks), including the authorized source text when a check must cite it. Supply a trusted local `--verify-worker` for executable checks and for Claude workspace intake. [Preflight the checker](references/evaluate-delivery.md#preflight-the-checker). Start the run in a private directory under the project's output folder with the owner's call budget. Return the verified artifacts, check evidence, and [shareable telemetry](references/run-record.md#shareable-telemetry). At an owner, allowance, or capability gate, report the saved run and the decision it needs.
