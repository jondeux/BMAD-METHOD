# Instruction candidates

All submitted candidates are approved and recorded in [AGENTS.md](AGENTS.md#approved-learnings).

## Approved on 2026-11-27

1. **Show how source material enters a workflow.** When mapping BMad entry points, include raw documents, research, and recordings as a distinct starting point and verify which formats the workflow reads through the host. This helps users turn existing material into actionable context. Evidence from 2026-11-27: the owner noticed this route was missing, and `bmad-ingest`, Deep Recon Process, and `bmad-shard-pro` cover different goals in the checkout. Scope: BMad workflow maps and onboarding guides.
2. **Calibrate typed routing decisions on the intended workload.** Preserve the selected-option probability and any confidence statistic as separate signals. Evaluate both on labeled intake before gating on them. Evidence from 2026-11-27: Jev’s documentation defines its confidence as a summary derived from the answer probabilities. Scope: BMad model routing and model-upgrade plans. [TypeSafe confidence documentation](https://docs.typesafe.ai/confidence)
3. **Check included usage separately from sign-in.** For subscription-only BMad runs, verify that the selected host will use the included allowance and can pause before drawing paid credits. Evidence from 2026-11-27: OpenAI documents that a signed-in Codex session may draw available purchased credits after the allowance is exhausted. Scope: intake and delivery billing checks. [OpenAI credit behavior](https://help.openai.com/en/articles/12642688-using-credits-for-flexible-usage-in-chatgpt-personal-plans)
4. **Preserve the owner's workflow boundary when adding a gate.** When the owner places a gate inside a saved workflow, design it around the existing run and authority record. Prove that incompatible old runtimes reject any new persistence protocol safely. Evidence from 2026-11-27: the owner identified Intake as Delivery's in-run route phase, and the current controller validates the persisted attempt version. Scope: Autonomous Delivery gate and state-format upgrades. [Controller](skills/method/bmad-deliver/scripts/deliver.py)

## Approved on 2026-11-28

5. **Verify the subscription inference endpoint separately from the quota probe.** In a Codex plan-only integration, keep inference on the first-party ChatGPT Codex endpoint and smoke-test the actual worker. The account RPCs can succeed even when a model endpoint override directs inference to the API. On 2026-11-27 the quota check passed, the API URL override produced a permissions error before generation, and the subscription endpoint completed a typed delivery. Scope includes Codex subscription adapters and their regression tests. [Codex provider source](https://github.com/openai/codex/blob/main/codex-rs/model-provider-info/src/lib.rs)
6. **Preserve stored credentials during subscription preflight.** Use read-only account inspection and reject an ineligible authentication method at the gate. Codex tests show that forcing a different login method can remove stored credentials. On 2026-11-27 a disposable API-only account check verified that the read-only guard paused and left the file byte-identical. Scope includes authentication checks for existing CLI sessions. [Codex authentication tests](https://github.com/openai/codex/blob/main/codex-rs/login/src/auth/auth_tests.rs)

7. **Keep accounting updates separate from intake revisions.** Preserve pending receipt eligibility and the intake revision when the owner changes the call budget or provider allowance. On 2026-11-28 the recovery tests showed that the earlier budget update could retire a pending classifier attempt even though its inputs were unchanged. The revised controller adopts the original late receipt after those updates. Scope includes Autonomous Delivery recovery and intake state transitions. [Recovery tests](skills/method/bmad-deliver/tests/test_delivery.py)
8. **Run the documented rollback against the archived release.** Verify the archive against its separately published digest, use the archived version's compatibility checker, and open a representative saved run. On 2026-11-28, v0.4.0 review found that the installer expected an internal checksum file missing from the portable v0.3.0 archive. The corrected procedure succeeded with the actual archive and a saved code run. Scope includes Autonomous Delivery packaging and maintenance guides. [Release installer](tools/package_delivery_beta.py)

9. **Verify the installation through the user’s launcher.** Confirm the version and enabled state in the same plugin registry the user opens, then verify that its entry skill is available. On 2026-11-28, the hosted v0.4.0 cache and the isolated install passed while the workspace’s local marketplace still offered v0.3.0. Scope includes Autonomous Delivery release handoffs and plugin installation checks.
